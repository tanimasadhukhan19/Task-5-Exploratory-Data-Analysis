# Task 5: Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis on the Titanic dataset using Python.

## Objective
To identify patterns, trends, relationships, and anomalies using statistical analysis and visualization.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Dataset information using `info()`
- Statistical analysis using `describe()`
- Frequency analysis using `value_counts()`
- Missing value and duplicate checking
- Histograms and boxplots
- Scatterplots
- Pairplot
- Correlation heatmap

## Key Findings
- Female passengers had higher survival rates.
- Higher-class passengers generally had better survival outcomes.
- Fare and passenger class showed a noticeable relationship.
- Age distribution and possible outliers were identified.

## Files
- `Titanic_EDA.ipynb` – EDA notebook
- `Titanic_EDA_Report.pdf` – Final report
- `train.csv` – Dataset
- `README.md` – Project information

## Conclusion
EDA helped identify important patterns and relationships in the Titanic dataset and improved understanding of data analysis and visualization.
